负责人已确认：**Ariadne**，**Private**。Python 分发名 `ariadne-cua`，内部模块名 `cua_guard`；本地继续使用 `项目开发/plugin-core`，保持已经验证的虚拟环境路径。以下候选作为决策历史保留。

|---|---|---|
| **Palimpsest / palimpsest** | 重写过而仍留下旧痕的羊皮卷，贴合记忆、版本与修复 | 文学性强、语义最贴题；拼写稍长，建议主选 |

| **LumenTrace / lumentrace** | 光与追迹的组合，中文可用“循光” | 易理解、便于产品展示；原创组合名的文献意象较弱 |

这些是命名建议，尚未进行商标或全网唯一性核验。组织内 slug 可用性在创建前通过 API 检查；不是要求包在 PyPI 全局同名。仓库名、README 标题与包元数据已统一至 Ariadne。
